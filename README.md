# 星迹 — iCloud 照片空间

一个原生 macOS 照片浏览器，通过系统 PhotoKit 读取这台 Mac 已同步的 iCloud 照片，并以星云、层叠、轨道和画廊四种空间方式呈现。

## 功能

- 星云：滚轮或纵向拖拽沿拍摄时间穿越；移动指针改变视角，捏合控制镜头距离，前后景自动虚化。
- 层叠：按主题聚成独立卡组，未识别照片单独成组；点击卡组展开为组内 CoverFlow，支持滚轮、拖拽、翻页按钮和位置滑块。点击中央照片查看高清大图，返回时收回卡组。
- 日期：所有模式左下角显示当前照片的年月日；悬停照片时优先显示这张照片的日期。
- 苹果相册：层叠默认直接沿用 PhotoKit 提供的用户相册、收藏、自拍、人像模式、实况、全景、截图、长曝光和 RAW 分组。同一照片可出现在多个相册中；未覆盖照片单列，仍排除视频。“自动主题”保留为独立选项。该功能不等于读取苹果相册内部的场景搜索或人物与宠物识别结果。
- 轨道：滚轮或拖拽旋转照片环；移动指针改变轨道纵深，捏合在近景弧线与完整圆环之间缩放。
- 画廊：全量网格懒加载；滚动浏览、悬停倾斜，捏合调整网格密度。
- 背景：右上角太阳/月亮按钮在黑色与白色背景之间切换，照片本身保持原色。
- 清晰度：默认关闭景深虚化；光圈按钮可开启轻微远景虚化。放大卡片按实际显示尺寸请求高清图片，尺寸升级时保留原有预览。
- 快速跳转：星云、层叠和轨道右下角提供上一张、下一张和位置滑块，可以快速抵达全图库中的任意位置。
- 简洁界面：纯色黑白背景，年份和主题收进菜单；移除方格、渐变、照片角标、重复计数和装饰说明。
- 流畅性：星云只绘制附近 36 张、轨道 20 张、层叠 21 张（图库索引仍完整）；输入按 60 Hz 合并，固定高清加载档位，识别结果批量更新。星云远处淡入、近处淡出，图片加载完成后短暂渐显。
- 全量索引：不再限制 360 张；读取图库中的所有静态照片与实况照片，自动排除视频。缩略图只在进入屏幕时按需读取。
- 智能主题：在本机依次识别全部照片中的演出现场、美食、人物、风景、宠物、城市、旅行和文档；使用精确场景标签与清晰图片，只有证据充分且领先其他主题时才分组，不确定结果放入“待确认”。不再把同一时间段的主题扩散给其他照片。系统标记的截图归入文档。
- 手动修正：打开单张照片后可修改主题，结果保存在本机并优先于自动识别。
- 事件卡组：层叠的分组菜单提供“事件”。跨日期、相邻照片间隔超过两小时或定位相距超过五公里时拆组；没有日期的照片单列。右键卡组可在本机重命名。
- 位置同步：四种模式共享当前照片，分别保留缩放状态。筛选排除当前照片时选择拍摄时间最近的结果；悬停不会改变保存位置。
- 实况照片：长按超过 350 毫秒静音播放，松开、拖动、切换模式或离开窗口即停止；普通点击打开大图。下载失败时保留封面，可重新长按重试。

## 下载安装

不想自己编译的话，直接下载打包好的版本：

**https://github.com/Justinchengpepe/star-trail/releases/latest**

- 通用二进制，同时支持 Apple Silicon（M 系列）和 Intel 的 Mac
- 要求 macOS 15 或更高版本

解压后把 `星迹.app` 拖进「应用程序」文件夹即可。

> **首次打开会被 macOS 拦下**，提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」。
> 这是因为应用只做了 ad-hoc 签名、没有 Apple 开发者证书，并不是应用本身有问题。
> 解决方法：**右键点击 `星迹.app` → 选「打开」→ 在弹窗里再点一次「打开」**，之后就正常了。
> 也可以一次性解除限制：
>
> ```sh
> xattr -cr /Applications/星迹.app
> ```

## 使用

1. 确保 macOS「照片」App 已开启 iCloud 照片同步。
2. 打开 `星迹.app`（下载版在「应用程序」里，自己编译的在 `dist/`）。
3. 首次运行时点击「允许访问照片」，在系统弹窗中授权。

应用不会上传照片。iCloud 中尚未下载的缩略图或原图，会由 macOS 照片服务按需下载。

主题识别使用 macOS Vision，在本机逐张处理。它可以识别演出场景、食物和画面文字，但不会仅凭人脸自动确认具体歌手姓名；如果舞台屏幕包含姓名，可通过顶部搜索框搜索识别出的文字。照片很多时可随时点击停止按钮，已完成的结果会保留。

识别缓存已升级，旧版自动标签不再直接用于分组；手动修正保留，旧缓存仍可恢复。新版需点击魔法棒重新识别。

本版要求 macOS 15 或更高版本。新增功能只保留事件卡组、跨模式位置同步和长按实况播放。照片不再进行相似收叠，也不提供自然语言语义搜索；原有日期、主题和识别文字搜索保持可用。

事件索引和事件名称存储在 `~/Library/Application Support/NebulaPhotos/photo-index.sqlite`。事件分组只读取拍摄日期和定位，在后台生成，不再运行相似度比较、向量生成或语义模型推理。旧版生成的模型和分析缓存不再加载；原始照片与手动主题修正保持不变。

## 从源码构建

在项目目录运行：

```sh
chmod +x build.sh
./build.sh
```

只需要 macOS 自带的 Swift 命令行工具，不依赖第三方库。脚本会分别编译 arm64 与 x86_64，再用 `lipo` 合成通用二进制，产物在 `dist/星迹.app`。

交互研究参考：[Carousel.SwiftUI](https://github.com/JuniperPhoton/Carousel.SwiftUI) 的连续位置控制和 [CoverFlow 示例](https://gist.github.com/Codelaby/3d80c1e475bf036399d97ee8eb5861be) 的空间卡片效果；实现保留原生 SwiftUI，不引入额外依赖。
